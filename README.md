# workshop-DOM
This is a simple shopping cart project built with HTML, CSS, and JavaScript (DOM manipulation).
It allows users to increase/decrease product quantities, like items, delete products, and automatically update the total price.

🚀 Features
➕ Increase product quantity
➖ Decrease product quantity (minimum 0)
🗑️ Delete items from the cart
❤️ Like/unlike products (toggle color)
💰 Automatic total price calculation
🧠 Technologies Used
HTML5
CSS3 (Bootstrap included)
JavaScript (DOM manipulation)
Font Awesome (icons)
